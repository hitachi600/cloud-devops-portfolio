A modern, ultra-responsive 2026 developer portfolio tailored for a **Cloud & DevOps Engineer** specializing in **AWS Cloud Architecture**, **Docker Containerization**, **CI/CD Automation**, and **Python Backend Engineering**.

## 🌟 Highlights & Features

- 🌌 **2026 Dark Glassmorphism Design**: Fluid aurora particles background, ambient lighting, and subtle micro-interactions.
- 💻 **Interactive Cloud Terminal CLI**: Visitors can run real commands (`help`, `skills`, `aws s3 ls`, `projects`, `hire`, `cat resume`, `whoami`).
- 🪣 **Deep-Dive Cloud Architecture**: Interactive breakdown of AWS S3, Boto3, IAM least-privilege policies, and presigned URLs.

- ⚡ **Pure Vanilla Stack**: Built with zero bulky frameworks — fast, lightweight, and deployment-ready.

## 🚀 How to Run Locally

Simply double-click `index.html` or run with Python:

```bash
python -m http.server 8000
```
Open your browser at: **http://localhost:8000**

---

## 🌐 Deploy to GitHub Pages (Free Hosting)

1. Create a repository on GitHub (e.g. `gautham-portfolio` or `hitachi600.github.io`).
2. Push all files inside this `portfolio/` folder to the repository.
3. In your GitHub repo settings, navigate to **Pages** ➡️ select **Branch: main** and click **Save**.
4. Your portfolio will be live at: `https://hitachi600.github.io/`!
